# Autonomous Vehicle Prototype – Version 1

This folder contains the first version of the Tinkercad prototype and related simulation files for the Autonomous Vehicle Systems Engineering project.

The current version represents the initial system integration and proof-of-concept design, including:
- Arduino-based control architecture
- Motor driver integration
- Sensor connections
- Preliminary autonomous vehicle behavior setup

This version is subject to further refinement and extension as the project evolves.

Future updates may include:
- Improved circuit organization
- Additional sensors or subsystems
- Optimized control logic
- Mechanical and structural refinements
- Contributions and enhancements from other project team members
- Integration updates based on testing and validation results

The repository will continue to be updated collaboratively throughout the development lifecycle of the project.
